# Kammahl — site oficial v5

Página estática pronta para publicar no GitHub Pages. Esta versão apresenta o produto, explica a
primeira Beta pública, mostra requisitos e instalação, esclarece privacidade e oferece canais de
download e feedback em português e inglês.

## Arquivos necessários

- `index.html`
- `favicon.svg`
- `assets/kammahl-hero.png`

Mantenha a estrutura das pastas ao enviar os arquivos.

## Publicação no GitHub Pages

Substitua esses arquivos na raiz do repositório público `Kammahl/kammahl.github.io`. O GitHub Pages
publicará a branch `main` conforme a configuração atual do repositório.

Antes de publicar, confirme se o download e a página da versão ainda apontam para a Beta vigente.
Nunca coloque chaves de API, senhas, tokens, conversas ou dados pessoais neste repositório público.
