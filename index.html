03 // Chave de API

Sua IA, sua chave.

Para usar recursos de IA online, o Kammahl precisa de uma chave de API de um provedor compatível. Você adiciona sua própria chave nas configurações do programa.

O que isso significa?

O Kammahl não inclui créditos ilimitados de serviços externos. Custos, limites e disponibilidade dependem do provedor de IA escolhido pelo usuário.

Adicione a chave de API nas configurações do Kammahl.
Escolha entre os provedores compatíveis disponíveis no programa.
O consumo e a cobrança da API são definidos pelo próprio provedor.
Recursos que funcionem localmente podem não exigir uma chave de API.

04 // Filosofia

Assistente, não bot.

A proposta do Kammahl é ampliar sua compreensão do jogo, não substituir suas decisões. A arquitetura prioriza permissões explícitas, contexto controlado e transparência sobre o que o Companion está usando.

  • Sem automação de gameplay como objetivo do produto.
  • Permissões explícitas para recursos sensíveis.
  • Memória organizada para manter continuidade entre sessões.
  • Ferramentas e fontes separadas da camada de personalidade.
